## 3. 候选规则

1. **观察日：**每个自然月最后一个真实 SSE 交易日收盘后。由交易日历确定，不能用月历日替代。
2. **指标：**截至观察日 T，取最近 250 个真实交易日（含 T）的因果复权收盘，做简单算术平均。少于 250 条、缺 bar/因子或日期不唯一均停止，不缩短窗口。
3. **复权：**只用于信号。沿用现有 2009-01-05 固定锚点转换：每个 d≤T 的信号价使用 raw close(d) × adj_factor(d) / adj_factor(2009-01-05)；所有读取日期及因子不得晚于 T。按确定性 Decimal 算术比较。成交与账户估值一律使用 raw open/close。
4. **状态：**空仓且信号价 > SMA250，建立一笔买入目标；持仓且信号价 < SMA250，建立一笔清仓目标；相等时维持。持仓时再次 > 不加仓；空仓时 < 不下单。不做杠杆、固定止盈或固定止损。
5. **初始触发同样使用上述规则：**2017 年最后一个交易日只生成初始目标，成交最早发生在 2018 第一个可执行开盘。

## 4. 订单与执行模拟

- 每次买入在订单实际尝试成交时，用可用现金扣除佣金和滑点后，购买最大可负担的 100 份整数倍；余额不为负。卖出目标为全部可卖持仓。
- T 收盘产生订单意图，T+1 或其后首个符合冻结模拟条件的开盘尝试成交。使用 raw open、既有 0.001 最小价格变动单位并向不利方向取整；买价向上、卖价向下。日线数据只能支持此模型，不能证明开盘队列优先、盘中未披露临停或保证实际成交；输出须称模拟成交，不得称真实可成交承诺。
- 复用 `simulate_fill` 的开盘容量模式：按前一交易日已知成交量的 10% 容量限制，容量不足或停牌、涨跌停、T+1、现金不够等暂不可成交时，记录原因并于后续交易日重试。该 10% 是现有执行模型的模拟容量假设，不是 Illya 的实际券商成交证据；基础与压力两情景共用。
- 新月末目标若与尚未成交的反向挂单相冲突，撤销旧单并留痕；同方向未成交单继续重试，不能重复建单。窗口末剩余挂单取消，绝不在 2021 年补成交。
- 费用：买卖两侧佣金均为 max(成交金额 × 0.0003, 5 元)，每笔订单按分以 ROUND_HALF_UP 结算；Illya 已确认无其他手续费，印花税和过户费设为 0。基础单边滑点 0.0005，压力单边 0.001，均为模拟假设而非观察到的实际滑点。现金收益率为 0；Sharpe 的无风险利率设 0，仅作辅助说明。
- 每条成交记录至少绑定信号日、方向、订单、执行尝试日、原始开盘价、滑点调整价、数量、费用、成交/拒绝原因和剩余挂单状态。不能将策略计划或模拟成交写入正式交易账本。

## 6. 买入持有基准与期末值

买入持有账户与候选账户在同一个账户起始时点（2018 年首个 SSE 交易日开盘前）独立建立，均为 5,000 元现金、零持仓、零应收。基准在该时点无条件创建一次买入意图，完全独立于候选 MA250 信号；仅可被两账户共同的成交约束顺延。候选当时可空仓，基准不得等待候选首次买入，也不得把两者“实际首次成交日”强行设成相同。基准买入后持有至窗口末，不因候选信号卖出、不追加买入、不单独再投资分红。

两账户使用相同的 100 份整数单位、佣金、滑点、前一交易日成交量容量、停牌/涨跌停、T+1 与余额规则。基准买入意图若暂不可成交，只按共同规则逐日重试至其自身首个模拟可执行开盘或窗口截止。即使其因真实数据约束晚于候选或早于候选成交，仍按各自真实账单比较，不用候选信号决定基准入场。

每个账户均报告两种期末值：

- **账面期末总资产：**日终现金 + raw close 持仓市值 + 未支付分红应收；不实际强制卖出。
- **估算退出后终值：**先在该账户真实数量与真实资金口径上，以窗口末 raw close、相同单边滑点/不利 tick 取整、佣金模型计算假设清仓成本；再从该账户总资产扣除。候选与基准对称计算，退出成本独立列示，不生成卖单、不改变账面持仓/现金/回撤。2020 归一须先按本账户真实规模算出成本，再与终值使用同一比例缩放；不可在归一后的 5,000 元账上重新应用 5 元最低佣金。

若期末持有量、价格、费用或应收无法核定，退出后终值标为数据不足，不用零成本代替。
## 7. 区间口径与固定指标算法

### 风险曲线和期末值

- **全期与 2018–2019：**各自连续账户的风险曲线均以 2018 首个 SSE 交易日开盘前 5,000 元初始 NAV 为期初点，之后纳入窗口内每个实际交易日 EOD NAV。期初点参加收益、回撤和 Sharpe 的相邻日收益计算，但不参加平均敞口/现金。
- **2020：**不重置任何真实账户、订单、持仓批次、现金或应收。以各自 2019 最后 SSE 交易日 EOD 的实际 NAV 为段初点；后续采用每个 2020 实际交易日 EOD。段内比较曲线统一乘以 `scale = 5,000 / 各自 2019 年末实际 NAV`，所以段初点为 5,000。候选和基准各自独立缩放。
- **期末退出费用：**全期及 2018–2019 按相应真实账户状态计算；2020 先按 2020 年末真实账户的实际持仓数量、佣金最低额和滑点算出估算退出成本，再把 2020 期末资产及退出成本乘同一个 `scale`。不在缩放账上重新套 5 元最低佣金。原始连续账单、未缩放成本和归一后比较值都保留。

### 指标公式和日期

- **窗口日期：**全期为 2018 首个 SSE 交易日的期初点至 2020-12-31 最后 EOD；研究段为同一起点至 2019 最后 SSE 交易日 EOD；2020 段为 2019 最后 SSE 交易日 EOD 至 2020-12-31 最后 EOD。报告实际起止日和自然日间隔；缺少边界日/必要 NAV 即停止。
- **CAGR：**`(终值 / 初值) ** (365 / 两边日期之间的实际自然日数) - 1`，使用 ACT/365，不使用交易日数。2020 以归一后的 5,000 元段初点和该段归一终值计算；另列连续账户原始账单。
- **Sharpe：**逐点计算相邻风险曲线的日收益 `r_i = NAV_i / NAV_(i-1) - 1`；年化为 `mean(r) / population_std(r) × sqrt(252)`，无风险利率为 0。标准差使用总体方差 `sum((r-mean)^2)/N`，与既有指标公式一致；无日收益样本时标为不适用，零标准差时显示 0。仅作辅助指标。
- **最大金额回撤：**逐点取段内截至当日的最高 NAV，计算 `running_peak_NAV - current_NAV`，其最大值为金额回撤；在原始连续账户按实际人民币金额计算，2020 段按缩放曲线计算。金额回撤不是 5,000 元乘回撤百分比。
- **最大比例回撤：**独立计算 `(running_peak_NAV - current_NAV) / running_peak_NAV` 的最大值。分别为金额、比例最大值登记自己的峰值日期、谷值日期和恢复日期；两种最大回撤可以对应不同峰谷。恢复日期为谷值后首次 NAV 回到该最大值所属峰值 NAV 的日期；截至窗口末未恢复则标未恢复和已历交易日数。
- **平均敞口/现金：**只取窗口内真实交易日的 EOD 快照（2020 使用原账户 EOD 数量与 NAV）。分别报告 `mean(持仓 raw-close 市值 / 当日 NAV)` 与 `mean(现金 / 当日 NAV)`；初始 5,000 元点和 2019 年末 2020 段起点不额外计入平均值。分母非正时停止。
- **金额与派生值精度：**账户现金与逐笔费用按分以 ROUND_HALF_UP 结算；持仓份额为整数。派生 CAGR、Sharpe、比例回撤等使用 Decimal precision=28 计算并以 ROUND_HALF_UP 输出到小数点后 10 位。账单报告各窗口各账户的期末总资产、估算退出后终值、净收益、费用/滑点、交易与受阻次数、平均敞口/现金、期末持仓/应收，以及上述指标与各自日期。所有对比同时保留原始与归一口径。
## 8. 比较分类与结论

对每个窗口和成本情景使用同一 5,000 元等值口径：

- `ΔW = 候选估算退出后终值 − 买入持有估算退出后终值`。
- `ΔD = 买入持有最大回撤金额 − 候选最大回撤金额`。两者均以元计，正值表示候选较优。2020 先依第 7 节各自缩放。
- `同向改善`：ΔW≥0 且 ΔD≥0，至少一项严格大于 0；`无增益`：两项均为 0。
- `收益改善伴风险代价`：ΔW>0、ΔD<0；`风险改善伴收益让步`：ΔW<0、ΔD>0。
- `同向不利`：ΔW≤0 且 ΔD≤0，至少一项严格小于 0。任何窗口或基础/压力情景分类/方向不一致都显著标注“跨窗口或压力不一致”，不挑最好窗口或滑点。

不设 ΔW、ΔD、成本缓冲、2:1 偏好或其他机械策略通过线，不生成 strategy pass。若全期和 2020 在基础、压力情景均同向改善，只能称“初步值得继续独立研究”，不能据此采用或授予资格。若全期和 2020 的两种成本情景均满足 ΔW≤0、ΔD≤0，且存在严格不利差异，结论为“不支持额外交易/暂不采用”；完全相等单列“无增益”。可信但存在收益/风险取舍时，以人民币列明并写“存在取舍，待 Illya 权衡”；跨段或压力方向不一致时写“结果不稳定/证据有限”。数据、会计、执行或因果口径不可信时停止并写“证据不足”，不把内部测试通过说成策略通过。

### 四路径独立账务复核

四条路径完成后，在输出研究结论前，对同一批已产出的原始价格、成交尝试/成交、权益事件和日终账单做一次独立核账；它是本 batch 的验收检查，不是新增策略、路径或回测。

独立检查器使用一套最小专用实现，逐笔从原始成交价格和事件重算佣金/滑点、现金、整数持仓、T+1 可卖量、记录日权益、除息应收、支付日 EOD 到账、每日日终 NAV，以及本协议定义的 CAGR、Sharpe、两种最大回撤及敞口指标。它不得把主运行器的费用、填单、`DividendLedger`、NAV 或指标函数作为期望值 oracle；可共享已冻结的只读原始输入，但必须独立重算账务与指标。货币比较精确到分、份额/日期/交易及事件计数精确相等；派生比率按 Decimal precision=28 计算后 ROUND_HALF_UP 量化到小数点后 10 位并逐字段精确比较，不设额外误差容忍。任一四路径账单或指标出现不一致，批次记录写 `ABORTED`、保存差异、停止发布结论；不修后复跑本批。
