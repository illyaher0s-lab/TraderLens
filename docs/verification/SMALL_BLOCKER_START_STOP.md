# CARD003 — 真实成交结构化记录

**MAINLINE STEP:** 5 · **STATUS:** 等待用户本人验收 · **进度:** 3/20，剩余17

- **BEFORE:** 成交记录依赖自由文本，不能稳妥保存实际成交日、ETF三位小数或未核实身份。
- **AFTER:** 首页 `/` 仍只有“记录成交”和“持仓/观察”两个入口。成交表单在 `/trades/record`，观察列表在 `/observations`。成交写入仍只有 `POST /api/agent/workbench/execution-feedback`，使用同一 `_submit_execution_feedback` 和 `LiveTradeDB(get_live_trade_db_path())`，正式数据库为 `data/live_trade.db`。
- **身份:** 新增只读 `GET /api/agent/workbench/security-identity/{code}`。股票复用现有身份解析器，场内基金通过现有 Tushare 客户端的 `fund_basic` 查询。实查 `510880` 返回 `510880.SH`、华泰柏瑞上证红利ETF、`fund/fund_share`。未查到时名称和单位保持未知，稳定代码不随名称查询结果变化。
- **字段与边界:** 代码、方向、实际成交日、价格、数量和已成交确认是核心事实；费用、来源、买入理由和个人退出计划可空。金额以 Decimal 计算，`3.215 × 2000 = 6430.000`。卖出须从五项中选择原因。股票买入数量异常只提醒并要求确认实际成交，卖出零股可登记。成交日与录入时间分开保存；补录的个人计划显示为回忆，不生成或关联 Action Plan。空买入理由保存为空，列表显示“未记录”；空费用显示“未知”。
- **回读:** `/api/observations` 从同一账本读取买卖日志；旧记录缺少成交日期时仍为“未知”。Agent 对话不写成交，系统建议来源也不自动关联已验证策略。
