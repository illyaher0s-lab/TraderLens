**计划覆盖：**
1. **8个核心契约**：
   - BacktestUniverseSpec（历史回测 universe）
   - ForwardWatchlistSnapshot（前向观察清单，类型隔离）
   - StrategyDraft（Hypothesis Builder 输出容器）
   - ResearchProtocolSnapshot（研究协议冻结快照）

2. **35个 TDD 子任务**，按"失败测试 → 最小实现 → 验证通过"顺序拆分

3. **硬边界要求**：
   - BacktestUniverseSpec 与 ForwardWatchlistSnapshot 类型层面不可互换

   - 除 StrategyPromotionReducer 外，任何路径写 prototype_passed 都失败
   - Append-only 存储，不删除失败记录

4. **数据库设计**：
   - 7个新表（strategy_drafts, research_protocol_snapshots, oos_evaluation_ledgers, immutable_backtest_reports, prototype_gate_results, strategy_promotion_records）
   - 唯一约束防止跨 theme 复用 OOS 窗口
   - 外键约束保证引用完整性

5. **关键架构决策**：
   - 扩展 ResearchDB（而非独立 StrategyDB）
   - PrototypeGateResult 扩展 stable.py（新字段 optional）
   - Hash 三元组（strategy/data/gate）确定 OOS 评估身份
